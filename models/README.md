# Dossier models

Place tes fichiers `.glb` ici, puis ajoute-les dans `MODELS` dans `index.html`.

Exemple :
```js
const MODELS = [
  { name: "Duck (démo)", url: "https://threejs.org/examples/models/gltf/Duck/glTF-Binary/Duck.glb" },
  { name: "Mon kart", url: "./models/kart.glb" }
];
```

Conseil taille APK / GitHub : vise < 15 Mo par GLB (Draco / meshopt).
